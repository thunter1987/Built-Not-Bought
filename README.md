# Built Not Bought Project App

> Document The Build. Track The Performance.

## Project Overview

Built Not Bought is a full-stack web application for performance car enthusiasts who want to track their vehicles, modifications, and performance results in one place.

Many car enthusiasts do not simply buy a finished performance car. They build it over time through modifications, tuning, maintenance, and testing. Built Not Bought gives them a dedicated place to document that journey.

Users can create a garage, add cars, log modifications, record dyno results, track acceleration numbers, log lap times, and visualize how their car’s performance has improved over time.

This project is intended as a portfolio-friendly full-stack application using React, Python, SQLAlchemy, and PostgreSQL.

## Problem

Performance car enthusiasts often track their builds using:

- forum posts
- spreadsheets
- phone notes
- dyno sheet screenshots
- receipts
- scattered maintenance records

This makes it difficult to understand:

- how much power the car has made over time
- which modifications were installed and when
- how much money has been spent
- whether performance actually improved after upgrades
- what maintenance has been done for street or track use
